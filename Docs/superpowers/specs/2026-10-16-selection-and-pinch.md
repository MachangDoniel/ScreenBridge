# Selection and annotation editing

The floating toolbar is ordered Select, Pen, Rectangle, Ellipse, Arrow, Edit annotations, Undo, Redo, More, Hide. Select is active by default and inspects existing app objects. It uses purple; drawing tools use blue; Edit annotations uses orange. Dividers separate these groups from history and settings.

Edit annotations selects existing markup, supports dragging, and shows a small delete control. A two-finger pinch resizes the selected annotation around its center, previews continuously, and commits one undoable edit when released. There are no shrink/enlarge buttons.

The panel can be dragged using its grip or any empty panel surface. More retains colors and area selection. Delete all replaces Resume app and clears annotations and inspection selections as one undoable operation, returning to Select.

The Demo app has an opaque 1024-pixel AppIcon, generated by its checked-in AppKit script.
