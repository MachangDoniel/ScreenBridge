# Slim debugging toolbar

User-directed revision: a single icon row ordered Select, Area, Pen, Ellipse, Rectangle, Arrow, Undo, Redo, More, followed by an × hide control. A small grip moves the toolbar to any corner. No headings or instructional hints.

More contains color choices and the existing inspection, log, and report settings. Hide collapses the toolbar to a small reopen control.

A separate row beneath the toolbar appears only when a selection, selected area, annotation, or report description exists. Send prepares delivery to the Mac inbox; the Claude icon prepares delivery to Claude Desktop. The report sheet retains all destination choices.

Undo and redo restore annotations and selection state together. A new edit clears redo history. History retains the most recent 50 edits.
